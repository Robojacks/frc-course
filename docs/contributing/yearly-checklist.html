Yearly Checklist#

Do this every fall, before new members start the course.

After the WPILib kickoff release#

  • Update the setup lesson for the new installer
  • Check the JDK version used in the CI example (Lesson 16)
  • Skim the WPILib release notes for renamed or deprecated classes used in code examples
  • Rebuild the code examples in a fresh project to confirm they still compile

Links#

  • Click every link on the Resources page
  • Spot-check the Read this links on each lesson
  • Run mkdocs build --strict (catches broken internal links)

Content#

  • Update hardware references to match this year's robot (motor controllers, pneumatics module)
  • Ask last year's new members which lesson was most confusing, and fix it
  • Hand ownership of the site to a returning member before seniors graduate
