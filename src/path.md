# Course Path

The **Lessons** tab is organized by topic, and the **Labs** tab by robot. This page puts them in **one order**: read a lesson, then practice it in a lab, then move on. It's the order to follow if you're new.

| You'll see | Means |
|---|---|
| <span class="path-kind">Lesson</span> | Read it and do its **Try it** exercises. Most run in simulation on your laptop. |
| <span class="path-kind path-kind-lab">Lab</span> | Hands-on, on the test bed or the West Coast Drive. Each lab builds on the one before it. |
| → practiced in | The labs where that lesson's ideas get used on real hardware |

Every lesson and lab also has a box under its title showing where it fits, and its **Previous** and **Next** buttons follow this order.

!!! tip "No test bed or robot today?"
    Keep going with the lessons, and do the [XRP lessons](project/10-xrp.md) on an XRP or in simulation. Come back to the labs when you have the hardware. The labs stay in number order, so you'll always know which one is next.
